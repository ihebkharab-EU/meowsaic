# Meowsaic

A puzzle game: send the cats round the loop and clear the mosaic.

This repository holds the test build as a home-screen web app.

- `index.html` is the whole game.
- `manifest.webmanifest`, `sw.js` and the icons make it installable and playable offline.

To install on an iPhone: open the site in Safari, tap Share, then "Add to Home Screen".
